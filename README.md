# Explorando Padrões de Projetos na Prática com Java

Repositório com a implementação de Chain of Responsibility sugerida pelo desafio prático da DIO.

Neste exemplo foi implementado um fluxo simples de suporte técnico:
- SuporteNivel1: Trata dúvidas simples. Se não puder resolver, passa adiante.
- SuporteNivel2: Trata problemas complexos.
